# Inbox Dump

## ⚡ Quick Notes
- Think of `@mui/material` as just a giant `index.ts` file.

When you write:

```
import { Button } from '@mui/material';
```

you are **not** importing directly from the Button module.

You are importing from the package root, which then forwards/re-exports Button for you.

Conceptually, MUI has something like this internally:

```
// node_modules/@mui/material/index.tsexport { default as Accordion } from './Accordion';export { default as Alert } from './Alert';export { default as AppBar } from './AppBar';export { default as Box } from './Box';export { default as Button } from './Button';export { default as Typography } from './Typography';// hundreds more...
```

So your code:

```
import { Button } from '@mui/material';
```

becomes conceptually:

```
import { Button } from './node_modules/@mui/material/index';
```

Then the index file says:

```
export { default as Button } from './Button';
```

which eventually resolves to:

```
./Button/Button.tsx
```

---

By contrast:

```
import Button from '@mui/material/Button';
```

skips the giant index entirely.

It goes directly to:

```
./Button/index.ts
```

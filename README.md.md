This vault is used for:

- Daily office work tracking (Jira-based)

- Long-term career memory

# 📁 Folder Rules

## 00-Dump (Inbox / Raw Capture)

This is a **temporary holding area**.

Use it when:

- In a meeting
- Get a quick idea
- Don’t have time to organize

Rules:

- No structure needed
- Everything is messy by design
- Clean it later (move to proper folders)

---

## 01-Daily-Logs (Daily Work Tracking)

This is your **main work diary**.

Each file = one day:

Example:

```
2026-05-16.md
```

Contains:

- Jira tasks worked on
- what you did during the day
- blockers
- quick notes
- learnings

Purpose:

- standup preparation
- weekly reporting
- performance tracking

---

## 02-Projects (Work Knowledge Base)

All office project-related knowledge lives here.

### Current Project: `nxtthing`

Structure:

### 📌 Architecture

- System design notes
- frontend/backend structure
- data flow

### ⚙ Features

- Feature breakdowns
- implementation notes
- technical decisions

### 🤝 Meetings

- sprint planning notes
- discussions
- decisions made

Rules:

- Everything must be related to project context
- Use links between notes when possible (`[[note]]`)

---

## 03-Zettels (Knowledge System)

This is the **personal knowledge layer (Zettelkasten)**.

Each note = ONE idea only.

Examples:

- one concept (e.g. JWT refresh strategy)
- one bug insight
- one React pattern
- one architecture decision

Rules:

- Small notes only
- No long documents
- Must be reusable and linkable

Use links:

```
[[Authentication Flow]][[React Query Cache]]
```

---

## 99-Attachments

Used for:

- screenshots
- API responses
- UI images
- files from meetings or debugging

No notes here.

---

## 99-Templates

Reusable note formats:

- Daily log template
- Zettel template
- Project note template
- Meeting template

Purpose:

- speed up writing
- keep consistency
- reduce thinking overhead

# ⚙️ Core Workflow

## 1. Capture (Fast)

Anything goes to:

```
00-Dump
```

---

## 2. Organize (End of Day)

Move relevant content to:

- Daily Logs
- Projects
- Zettels

---

## 3. Refine Knowledge (Weekly)

Extract insights → convert to Zettels

---

## 4. Link Everything

Use:

```
[[Note Name]]
```

This builds your knowledge network over time.
